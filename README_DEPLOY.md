# YutuGram — часть 4

## Запуск локально
1. Установи Node.js 18 или новее.
2. В папке проекта выполни `npm install`.
3. Запусти `npm start` и открой `http://localhost:3000`.

## Что добавлено
- Создание групповых чатов кнопкой «+ Группа».
- Участники задаются логинами через запятую; каждый участник должен уже иметь аккаунт.
- История групповых сообщений сохраняется вместе с остальными сообщениями.
- Переменная `DATA_DIR` позволяет хранить данные на постоянном диске хостинга.

## Публикация в интернете (например, Railway)
1. Загрузи файлы проекта в приватный репозиторий GitHub. Не загружай папку `data/` и пользовательские загрузки.
2. Создай проект Railway из репозитория и укажи команду запуска `npm start`. Хостинг задаёт `PORT` автоматически.
3. Подключи постоянный Volume и установи `DATA_DIR=/data` (или путь, указанный хостингом).
4. Создай публичный домен и открой сайт по HTTPS. Для микрофона в голосовых звонках на внешних устройствах нужен HTTPS.
5. Проверь регистрацию и сообщения в двух браузерах.

**Важно:** этот архив не публикует сайт автоматически и не создаёт публичный URL — для этого нужен аккаунт хостинга. Перед настоящим публичным запуском нужно добавить полноценную серверную авторизацию с сессиями/токенами, защиту от частых запросов и базу данных вместо JSON-файлов. Текущая версия — прототип, не готовый к недоверенной публичной аудитории. Данные и загрузки должны храниться на постоянном диске, иначе хостинг может удалить их при пересборке.
