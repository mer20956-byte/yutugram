# YutuGram Premium

## Требования
- Node.js 18 или новее
- Интернет для загрузки Google Fonts (при его отсутствии интерфейс использует системные шрифты)

## Запуск
1. Распакуйте архив в отдельную папку.
2. Откройте терминал в этой папке.
3. Выполните `npm install`.
4. Выполните `npm start`.
5. Откройте http://localhost:3000.

Данные аккаунтов и переписок хранятся в `data/` и создаются автоматически. Загруженные вложения сохраняются в `public/uploads/`.
Файлы до 15 МБ; некоторые исполняемые и скриптовые расширения блокируются.

## Важно
Это базовый учебный проект для локального запуска. Для публичного развёртывания добавьте HTTPS, сессии/токены и авторизацию API, ограничение частоты запросов, CSRF-защиту и отдельное хранилище файлов. В текущем варианте API истории сообщений и загрузка файлов не привязаны к подтверждённой серверной сессии.
