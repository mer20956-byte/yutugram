# YutuGram — видео-лента

## Что добавлено
- Вкладка 🎬 Лента в боковой панели.
- Добавление ссылок TikTok, YouTube, Instagram, VK, Rutube и X/Twitter.
- Общая лента, сортировка по новизне и фильтры Все / TikTok / YouTube / VK.
- Общие лайки, комментарии в модальном окне, пересылка ссылки в личный чат, личное избранное и удаление автором.
- События Socket.IO `video-added`, `video-liked`, `video-commented`, `video-deleted`.
- Данные ленты хранятся в `data/videos.json`.

## Запуск локально
Требуется Node.js 18+.

```bash
npm install
npm start
```

Откройте http://localhost:3000.

## Файлы
- `server.js` — сервер/API и Socket.IO.
- `public/index.html` — интерфейс.
- `package.json` — зависимости и команда запуска.

## Важно перед публичным запуском
Текущая архитектура приложения передаёт логин от клиента в API и не имеет полноценной серверной сессии/токенов. Это соответствует существующей архитектуре проекта, но недостаточно для безопасного публичного сервиса: пользователь может подделать login в запросе. Перед открытием для широкой публики нужно добавить серверную аутентификацию и ограничение запросов. JSON-хранилище и загруженные файлы требуют постоянного диска/тома на хостинге, иначе могут пропасть при пересборке. Некоторые платформы ограничивают встраивание видео через iframe; для таких роликов ссылка на исходный пост остаётся доступна.
